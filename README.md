# cluster_scripts

A collection of scripts used to run and manage bioinformatics analyses and pipelines on the lab's cluster.

The scripts are organized into two directories according to their main purpose:

- `annotation/`: Scripts for genome annotation and functional characterization. 
- `compare/`: Scripts for genome characterization and comparative analyses, including taxonomic classification, genome quality assessment, and other analyses that facilitate comparisons between genomes.

## Usage

Most scripts are designed to be submitted or executed on the lab's cluster. Before running a script, make sure that the required software are available in the environment or loaded through the cluster's module system.

The scripts may need to be adapted depending on the input data, computational resources, and cluster configuration.
